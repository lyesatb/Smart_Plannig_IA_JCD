# Formats DOOH — repères

- **Digital premium**: forte visibilité, rotation, contexte urbain (gares / retail / premium districts).
- **Classic**: couverture / répétition, souvent moins cher mais visibilité variable.

Critères usuels:
- visibilité (angle, hauteur, obstruction),
- trafic (piéton / voiture),
- contexte (retail, transport, campus),
- disponibilité opérationnelle.
