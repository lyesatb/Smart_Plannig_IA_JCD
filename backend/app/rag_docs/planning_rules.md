# Planning rules — contraintes

- Un panneau **non OK** en maintenance est exclu.
- La **disponibilité** est un filtre dur (si indisponible: score très bas).
- En cas d’objectif “couverture”, diversifier quartiers / POI pour éviter la sur-concentration.
- En cas d’objectif “premium”, augmenter les poids visibilité + audience CSP+.
