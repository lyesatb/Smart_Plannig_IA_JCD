# Règles métier Smart Planning

Les recommandations doivent rester explicables.
Un panneau ne doit jamais être recommandé sans justification.
La validation humaine reste obligatoire avant activation.

## Campagnes premium
Prioriser :
- zones affaires,
- centres commerciaux premium,
- forte audience CSP+,
- formats digitaux visibles.

## Campagnes locales
Prioriser :
- proximité magasin,
- trafic local,
- disponibilité,
- coût maîtrisé.

## Campagnes nationales
Prioriser :
- grandes villes,
- couverture équilibrée,
- diversité géographique.
