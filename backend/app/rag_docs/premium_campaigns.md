# Premium campaigns — règles

- Une campagne **premium** privilégie la **visibilité**, la **qualité d’emplacement**, et la **cohérence audience** avant la quantité.
- Les zones **CSP+** (quartiers d’affaires, zones premium, hubs de mobilité) sont prioritaires.
- Les **gares** / pôles de transport sont pertinents si l’objectif inclut proximité / affinité flux CSP+.
- Éviter les emplacements avec contraintes opérationnelles (maintenance, indisponibilité, restrictions).
